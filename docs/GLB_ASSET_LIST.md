# Low-Poly GLB Asset List

Source: Gemini chat "3D Bruno Simon Car Design". Reference images: `../reference/`. **Status: all assets below are built** (single-player scope) in `../models/`, generated by the scripts in `../tools/blender/`.

## Conventions (clay style, reference 01)

- **Soft clay/toy look**: beveled, rounded edges, **smooth normals included**, satin finish. Props, bots and terrain use one shared vertex-color material (roughness 0.5, metallic 0). Render with `MeshStandardMaterial` (keep the loaded material; do **not** set `flatShading`). The hero car uses real clay materials (see below).
- Lighting to match the refs: a warm `DirectionalLight` at about 45° elevation casting soft shadows, plus a cool `HemisphereLight` (sky about #B8D0FF, ground warm) so shadows stay colorful. Use `ACESFilmic`/`AgX` tone mapping.
- Every file is **meshopt-compressed + quantized**: `new GLTFLoader().setMeshoptDecoder(MeshoptDecoder)`.
- **Quantization puts a scale and offset on each model's root node. Never overwrite the loaded root's position, scale or rotation.** Place a prop by adding it to a `Group` (or an InstancedMesh matrix multiplied by the node matrix) and set the transform from `props.json` on that group.
- LOD files: `name_lod0.glb` (full), `name_lod1.glb`, `name_lod2.glb`. Each LOD is built at lower detail (fewer bevel segments, fewer parts), not auto-decimated. Tiny props have only `lod0` and should be distance-culled instead.
- Collision: `name_col.glb` where a box or primitive isn't enough. It's never rendered; feed it to Rapier.
- Origin at the base center on the ground. Vehicles face **-Z in three.js** (+Y in Blender).
- Placement: `data/props.json` (three.js coordinates, meters). World layout (roads, river, bridges, lakes, camps, spawn): `data/world.json`.
- Regenerate **headless** so the live Blender session is never at risk: `node tools/blender/headless.mjs tools/blender/lib.py tools/blender/<nature|camp|structures|vehicles|terrain>.py [STEP=...]`, then `node tools/compress-models.mjs models`. The hero car is `tools/blender/hero_car.py` (step by step; a backup scene is in `tools/blender/hero_car.blend`), then `node tools/lods-from-showroom.mjs models/vehicles/car_hero_showroom.glb car_hero 0.3,0.1,0.03`.

- Rebuild with `node tools/blender/headless.mjs tools/blender/hero_car.py LOW=1 STEP=setup,body,wheels,roof,export BAKE=1 "EXPORT_TAGS=lod0:1,lod1:0.55,lod2:0.25"`, then `node tools/compress-models.mjs models`.

- coral-red body
- plum rack and bumpers
- charcoal-slate windows with rubber gaskets
- charcoal balloon tires with warm-white deep-dish rims
- olive canvas bag with tan straps, wood crate, spare tires
- eggshell "0" roundels, cream cartoon-eye headlights, amber turn signals

The subsurface scattering (0.08) only shows in Blender renders, because glTF can't carry it.

## Terrain (`models/terrain/`)

The world is 2.4 km × 2.4 km, centered on the origin, split into a 12 × 12 grid of 200 m chunks. Chunk `i_j` spans x = [-1200 + 200i, -1000 + 200i] and z = [1000 - 200j, 1200 - 200j] in three.js. Biomes: NW snow & ice, NE desert, SW sunset beach, SE forest & canyon.

| File | Count | Tris | Notes |
| --- | --- | --- | --- |
| `chunks/terrain_chunk_{i}_{j}.glb` | 144 | 2,048 each, plus roads | 32 × 32 grid (6.25 m), smoothed heights, soft per-vertex colors (lakes, camps, red-rock canyon rims, beach). Roads are a child mesh `terrain_chunk_{i}_{j}_roads`: crowned ribbons sitting 0.1–0.3 m above the ground, with dashed lines on the highway. Node origin at the chunk center. |
| `collision/collision_chunk_{i}_{j}.glb` | 144 | 2,048 each | Same surface without colors. Rapier trimesh, or read the regular grid as a heightfield |
| `world_backdrop_lod.glb` | 1 | 4,608 | Whole map at 50 m resolution. Sits at or below the real terrain, so it never pokes through loaded chunks. Always on, hidden by fog. |

## Data files

`data/props.json`, in three.js coordinates:

```json
{ "type": "tree_pine", "chunk": "7_3", "position": [410.5, 18.2, 320.0], "rotation": [0, 45, 0], "scale": [1.2, 1.2, 1.2] }
```

It has about 10,800 placements: about 5,800 forest pines, 1,240 snow pines, rocks, cacti, camps, the stunt park, the beach hangout and the ski lift. Group them by `chunk` + `type` into one `InstancedMesh` per chunk per type.

`data/world.json` holds the road polylines (with type and width; use them as bot waypoints), the river, the bridges, the lakes (ice), the oasis, the camps and the player spawn.
